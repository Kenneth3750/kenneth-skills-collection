# Document Generation Skills

Skills for generating and extracting Office documents programmatically using Python.

## Available Skills

| Skill | Description |
|-------|-------------|
| [docx-generation](docx-generation/SKILL.md) | Generate Word documents (.docx) with python-docx. Covers headings, tables, images, formatting, and template-based generation. |
| [xlsx-generation](xlsx-generation/SKILL.md) | Generate Excel spreadsheets (.xlsx) with openpyxl and xlsxwriter. Covers formatting, charts, formulas, and DataFrame export. |
| [office-document-extraction](office-document-extraction/SKILL.md) | Extract content from .docx, .pptx, and .xlsx files to traceable Markdown. Supports batch extraction and table parsing. |
