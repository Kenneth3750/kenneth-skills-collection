# AWS Skills

Skills for working with AWS services via CLI, SAM, and Cost Explorer.

## Available Skills

| Skill | Description |
|-------|-------------|
| [aws-costs](aws-costs/SKILL.md) | Calculate AWS costs for the last X days using Cost Explorer. Shows breakdown by service, monthly projections, and budget alerts. |
| [aws-deploy](aws-deploy/SKILL.md) | Deploy changes to AWS Lambda using SAM CLI. Includes build, preview, deploy, and log viewing with proper credential handling. |
