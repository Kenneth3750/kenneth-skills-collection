# Task Management Skills

Skills for structured task delegation and tracking between Build Lead and subagents.

## Available Skills

| Skill | Description |
|-------|-------------|
| [follow-todo](follow-todo/SKILL.md) | Follow TODOs assigned by the Build Lead. Enforces strict scope adherence, respects restrictions, and reports results in a structured format. |
| [task-delegation](task-delegation/SKILL.md) | Delegate tasks to subagents using structured TODO files. Keeps tasks small and focused with clear objectives, restrictions, and completion criteria. |
