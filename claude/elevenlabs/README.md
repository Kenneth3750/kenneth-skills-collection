# ElevenLabs Skills

Skills for working with the ElevenLabs API — voice AI, conversational agents, and cost tracking.

## Available Skills

| Skill | Description |
|-------|-------------|
| [elevenlabs-costs](elevenlabs-costs/SKILL.md) | Calculate ElevenLabs conversation costs for the last X days. Breaks down voice credits, LLM credits, and USD spent per agent. |
| [elevenlabs-conversation](elevenlabs-conversation/SKILL.md) | Get the full transcript of an ElevenLabs conversation by its ID. Includes metadata, tool calls, cost breakdown, and analysis. |
