# Agent Management Skills

Skills for creating and maintaining agents, tools, and skills in projects that use both OpenCode and Claude Code.

## Available Skills

| Skill | Description |
|-------|-------------|
| [agents-creation](agents-creation/SKILL.md) | Create and maintain subagents with proper field mapping between OpenCode and Claude Code. Includes model, tool, and permission conversion rules. |
| [skills-creation](skills-creation/SKILL.md) | Create and maintain project skills, synchronized between both platforms. Validates naming, frontmatter, and folder structure. |
| [tools-creation](tools-creation/SKILL.md) | Create custom tools with per-agent logic. Documents the differences between OpenCode custom tools and Claude Code scripts/hooks. |
